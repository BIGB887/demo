Six kinds of "automation"

the word covers more than one thing
01

Robotic process automation

Software that clicks, copies, and types the way a person would across existing apps — no AI required, though modern RPA often adds it for judgment calls.

  • Invoice data entry
  • Form-to-system transfers
  • Screen scraping legacy tools
02

Workflow & rules automation

If-this-then-that logic that routes work between people and systems based on conditions, without needing to "understand" content.

  • Approval chains
  • Ticket routing
  • Scheduled data syncs
03

Machine learning pipelines

Models trained on historical data to predict, classify, or score — the engine behind fraud flags, demand forecasts, and recommendations.

  • Churn prediction
  • Demand forecasting
  • Anomaly detection
04

Generative automation

Large language and diffusion models producing text, code, or images on request, usually with a human reviewing the output before it ships.

  • Drafting & summarizing
  • Code generation
  • Image & asset creation
05

Agentic automation

Systems that plan a sequence of steps, call tools, and adjust based on results — closer to delegating a task than issuing a command.

  • Multi-step research
  • Autonomous coding tasks
  • Tool-calling assistants
06

Physical & industrial automation

Robotics and control systems on factory floors and warehouses, increasingly paired with ML for vision and adaptive control.

  • Robotic arms
  • Warehouse picking
  • Predictive maintenance

Tool families worth knowing

categories, not endorsements

No-code workflow builders

connect

Drag-and-drop platforms that trigger actions across apps when an event happens — the connective tissue for small teams automating busywork.

RPA platforms

enterprise

Bots that operate existing software the way a person would, useful when there's no API to integrate against directly.

LLM APIs

generate

Hosted language models accessed by developers to add drafting, summarizing, or reasoning into their own products.

Agent frameworks

orchestrate

Libraries for chaining model calls with tool use and memory, so a single request can become a multi-step task.

Vector databases

retrieve

Storage tuned for semantic search, letting a system find relevant context before generating a response.

MLOps platforms

operate

Infrastructure for training, versioning, deploying, and monitoring predictive models in production.

Computer-use agents

act

Models that can see a screen and control mouse and keyboard directly, aimed at tasks with no API at all.

Document intelligence

extract

Systems that pull structured data out of PDFs, forms, and scans for downstream processing.

Conversational platforms

interface

Chat and voice front-ends that route a request to the right backend system or model.

Robotic process controllers

industrial

Software governing physical robotics — motion planning, safety interlocks, and coordination on a floor.

What you gain, what you're trusting

the honest version

Real benefits

  1. Speed on repetitive work. Tasks measured in hours can drop to minutes when the pattern is well-defined.
  2. Consistency. A rules-based or model-driven process doesn't get tired or skip steps under load.
  3. Coverage. Round-the-clock handling of a first pass, freeing people for judgment calls.
  4. Faster iteration. Drafts and prototypes that used to take days can take minutes to produce.

Real risks

  1. Confident errors. Generative systems can produce wrong output that reads as fluent and sure of itself.
  2. Data exposure. Feeding sensitive information into third-party tools without checking retention policies.
  3. Automation of bias. A model trained on historical data can repeat historical unfairness at scale.
  4. Accountability gaps. When an autonomous step causes harm, who is responsible often isn't defined in advance.

How we got here

selected milestones
1990s

Rules-based workflow tools

Early business process automation software formalizes routing and approvals inside large organizations.

2000s

RPA emerges

Bots learn to operate existing desktop software directly, avoiding costly system integrations.

2010s

ML goes into production

Predictive models move from research into fraud detection, recommendations, and forecasting at scale.

2017

The transformer architecture

A new model design makes large-scale language understanding and generation dramatically more practical.

2020–2022

Generative AI reaches the public

Text and image generation move from labs to consumer products almost overnight.

2023–2024

Tool-calling and retrieval mature

Models gain the ability to search, query, and act on live data rather than only generate text.

2025–2026

Agentic and computer-use systems

Systems take on multi-step tasks with minimal supervision, including operating software directly.
